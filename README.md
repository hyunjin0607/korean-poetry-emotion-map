## 검증 사례

### 사례 1
진달래꽃은 슬픔으로 분석되지만 단순한 슬픔보다 사랑과 헌신의 의미가 함께 나타난다.

### 사례 2
광야는 어두운 표현이 등장하여 슬픔으로 해석될 수 있으나 실제로는 희망과 저항 정신이 강하게 나타난다.

### 사례 3
님의 침묵은 침묵이라는 단어 때문에 부정적으로 분석될 수 있으나 작품 전체는 사랑과 신념을 담고 있다.

## 프로젝트 한계
