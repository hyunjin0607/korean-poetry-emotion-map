# 명시 감정 지도

한국 근대시 10편의 정서를 **감정 사전**과 **문학적 해석**으로 함께 분석하는 웹앱입니다.
시를 고르면 감정 분포, 행별 감정 흐름, 시어–감정–주제 다이어그램, 감정 이미지, 비슷한 감성의 시 추천을 볼 수 있습니다.

**바로 보기:** https://seokhee5hs.github.io/korean-poetry-emotion-map/

설치나 회원가입 없이 웹 브라우저만 있으면 됩니다. 파일은 `index.html` 하나입니다.

## 기능

| 메뉴 | 내용 |
|---|---|
| 시 본문 | 감정 사전과 일치한 시어에 정서별 색 밑줄 |
| 지배 정서·해석 | 주제, 화자, 표현 기법, 감상과 해석, 핵심 구절 |
| 감정 프로필 | 8대 정서 레이더 차트 (추천 1위 시와 겹쳐 비교) |
| 행별 감정 흐름 | 각 행에서 감지된 감정을 누적 막대로 표시 |
| 최종 분석 다이어그램 | 핵심 시어 → 정서 → 주제로 이어지는 흐름도 |
| 감정 이미지 | ① 감정 수묵화: 브라우저가 감정 비율과 시의 소재로 직접 그림 ② AI 이미지: 무료 API(Pollinations.ai)로 생성 |
| 비슷한 감성의 시 | 감정 벡터 코사인 유사도 상위 3편 |
| 감성 지도 | 10편을 주성분분석(PCA)으로 2차원에 배치, 축의 의미 해설 포함 |
| 전체 비교 | 시 × 정서 히트맵 |
| 내 시 분석하기 | 직접 입력한 시를 감정 사전으로 분석하고 비슷한 시 추천 |

## 분석 방법

1. **8대 정서:** 슬픔, 기쁨, 평온·달관, 희망·의지, 사랑·헌신, 성찰·부끄러움, 그리움, 원망·미움
2. **감정 사전 점수:** 각 행에서 정서별 시어(`LEX`)가 몇 번 나오는지 셉니다. 부분 문자열 일치라서 ‘말을 달리고’의 ‘달’처럼 문맥과 다른 일치도 생깁니다.
3. **해석 기반 프로필:** 반어·역설처럼 사전이 읽지 못하는 의미를 반영해 작품마다 정서 강도를 0–1로 넣은 값(`profile`)입니다.
4. **최종 점수:** `해석 프로필 × (1 − w) + 사전 점수 × w`. 화면 왼쪽 슬라이더로 `w`를 바꿀 수 있습니다.
5. **추천:** 최종 감정 벡터끼리 코사인 유사도를 계산해 높은 순으로 3편을 고릅니다.

## 감정 이미지 생성

- **감정 수묵화 (브라우저 생성):** 계정이나 인터넷 서비스 없이 Canvas로 그립니다. 감정 비율이 물감의 양을, 시에 나온 소재(달·별·꽃·새·길·물·눈·바람·해·구름·유리창·사람·산)가 화면의 사물을 정합니다. `PNG로 저장` 버튼으로 내려받을 수 있습니다.
- **AI 이미지 (무료):** [Pollinations.ai](https://pollinations.ai)의 무료 이미지 API를 씁니다. 가입이나 API 키가 필요 없고, 생성에 10–40초쯤 걸립니다. 서비스가 느리거나 막혀 있으면 `프롬프트 복사`를 눌러 Microsoft Designer, Google Gemini, ChatGPT 무료 계정에 붙여 넣어 만들 수 있습니다.

## 과제로 수정하기

1. 이 저장소 오른쪽 위의 **Fork**를 눌러 내 계정으로 복사합니다.
2. 내 저장소에서 **Settings → Pages → Branch: `main` / `/ (root)` → Save**를 누릅니다.
3. 1–2분 뒤 `https://내아이디.github.io/korean-poetry-emotion-map/`에서 내 버전이 열립니다.
4. `index.html`을 수정하고 커밋하면 사이트에 자동으로 반영됩니다. GitHub 웹 화면에서 연필 아이콘으로 바로 고칠 수도 있습니다.

### 고쳐 볼 곳

| 하고 싶은 것 | `index.html`에서 찾을 이름 |
|---|---|
| 감정 사전에 시어 추가·수정 | `const LEX` |
| 시 추가 (본문, 해석, 정서 프로필) | `const POEMS` |
| 정서 종류 바꾸기 | `const EMOS` (색은 CSS의 `--e1`~`--e8`) |
| AI 이미지용 장면 묘사 | `const SCENE` |
| 수묵화의 소재 인식 규칙 | `const MOTIFS` |
| 수묵화 색 | `const PIG` |

### 과제 예시

- 사전 기반 점수만 썼을 때(`w = 100%`)와 해석 중심일 때(`w = 0%`) 분석 결과가 어떻게 달라지는지 비교하고, 사전 분석이 틀린 사례를 찾아 원인을 설명하기
- 저작권이 만료된 시 3편 이상을 `POEMS`에 추가하고 해석 기반 프로필을 직접 정하기
- 감정 사전을 보완해 오탐(예: ‘달리고’의 ‘달’)을 줄이고, 고치기 전과 후의 결과를 비교하기
- 같은 시의 감정 수묵화와 AI 이미지를 비교하고, 어느 쪽이 시의 정서를 더 잘 드러내는지 근거를 들어 평가하기
